# 🕷️ Vipul Sharma — Portfolio

> Dark spider-web themed personal portfolio website showcasing my projects, skills, and experience in web development, machine learning, and cybersecurity.

🔗 **Live Site:** [vipul-portfolio-pi.vercel.app](https://vipul-portfolio-pi.vercel.app)

---

## ✨ Features

- Animated spider-web canvas background (mouse-reactive)
- Circular profile photo with spinning gradient ring
- Fully responsive design (mobile & desktop)
- Sections: Hero · Stats · Education · Experience · Projects · Skills · Certifications · Publication · Achievements

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | Vanilla CSS (custom properties, grid, flexbox) |
| Animations | Canvas API (JavaScript) |
| Fonts | Google Fonts — Orbitron, Rajdhani, Share Tech Mono |
| Icons | Font Awesome 6 |
| Hosting | Vercel |

## 🚀 Deploy Your Own

```bash
# Clone
git clone https://github.com/VIPULCODEX/protfolio.git
cd protfolio

# Deploy to Vercel
npm i -g vercel
vercel --prod
```
